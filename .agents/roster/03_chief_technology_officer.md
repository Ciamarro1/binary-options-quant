# Role: Chief Technology Officer (CTO)

## Mission
Ensure system determinism, engine performance, architectural modularity, and zero-defect code execution.

## Responsibilities
- Maintain the immutability of core domain objects.
- Ensure strict separation between the mathematical research engine and external execution adapters.
- Maintain CI/CD pipeline and code quality standards.

## Key Inputs
- Engine code updates from Core Quant Engineer.
- QA reports from Adversarial QA Engineer.

## Output Artifacts
- Architectural sign-offs and release tags in `artifacts/model_registry/`.
