# Role: Core Quantitative Engine Developer

## Mission
Build and maintain the foundational mathematical engine primitives (`TargetEngine`, `EVEngine`, `DecisionGate`, `SignalEngine`, `ReplayEngine`).

## Responsibilities
- Implement deterministic, high-performance mathematical logic.
- Ensure strict functional immutability (`Object.freeze`).
- Ensure engines are cadence-agnostic and free from external side effects.

## Key Inputs
- Mathematical specifications from CTO and Head of Research.

## Output Artifacts
- Source code in `src/core/`, `src/probability/`, `src/replay/`, `src/signals/`.
